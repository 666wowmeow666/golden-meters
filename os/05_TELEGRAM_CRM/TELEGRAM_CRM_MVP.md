# TELEGRAM / CRM MVP
**Статус:** концепция, не утверждённая спецификация.

## Цель
Дать сотрудникам интерфейс управления объектами через Telegram, не создавая независимую базу.

## Предварительные роли
- Администратор — пользователи, роли, настройки.
- Руководитель — просмотр всех данных и подтверждение критичных действий.
- Менеджер — работа с разрешёнными объектами.
- Маркетинг/контент — материалы и публикационные статусы.
- Наблюдатель — чтение без изменений.
Роли должен подтвердить клиент.

## MVP-сценарии
1. Поиск объекта.
2. Просмотр карточки и фото.
3. Создание черновика.
4. Редактирование разрешённых полей.
5. Скрытие/публикация с подтверждением.
6. История: кто, когда и что изменил.
7. Уведомления об ошибках синхронизации.

## Требования
Авторизация по Telegram user ID; права проверяются на backend; подтверждение опасных действий; мягкое удаление; журналирование; резервное копирование; секреты — только в защищённых переменных окружения.

Не включать без отдельного согласования массовые рассылки, полноценную CRM всех коммуникаций и автономные AI-действия.
