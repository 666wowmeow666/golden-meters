# TECHNICAL ARCHITECTURE
**Статус:** принципы; конкретный стек не выбран.

## Принцип
Сначала обследовать текущую систему. Интегрировать существующие компоненты, если это надёжно и экономически оправданно.

## Логическая схема
Сайт / Premium Pages / Telegram / CRM / Analytics  
↓  
API & Integration Layer  
↓  
Единая модель объектов и лидов  
↓  
Текущая база GOLDEN METERS или согласованное хранилище

Схема условная; фактическое решение — после аудита.

## Требования
Стабильные ID; API и разграничение прав; журнал изменений; резервные копии; мониторинг; обработка повторных запросов; dev/test/prod; документация интеграций.

## Безопасность
Секреты — только в secret manager/переменных окружения. Не коммитить `.env`, токены, пароли, ключи и персональные данные. Использовать тестовые/обезличенные данные и минимальные права доступа.
